About PlantPal

What is PlantPal?

PlantPal is an AI-powered plant health assistant that combines computer vision, natural language processing, and real-time weather data to give you personalised, accurate plant care advice.

How it works

1

Upload a photo

The AI scanner uses a fine-tuned MobileNetV2 model to classify leaf health: Healthy, Fungal Infection, Scorch, or Wilting — in under 2 seconds.

2

Multi-modal fusion

The result is cross-referenced with live weather (temperature, humidity, UV index) and your plant profile for higher-confidence diagnosis.

3

GPT-powered advice

Ask the AI chatbot any follow-up question. It remembers your plant, scan result, and previous conversation — no need to repeat yourself.

Technology stack

🐍 Python 3.11 + Flask
🧠 OpenAI GPT-4o-mini
🔬 TensorFlow / MobileNetV2
🗃️ SQLite + Drizzle-style queries
🌦️ OpenWeatherMap API
⚡ Vanilla JS + CSS Grid

Privacy

All data is processed locally. Uploaded images are analysed in memory and not stored permanently. Chat history is saved only for the current session to power conversational memory.
